# UI Bible — HEGEMA
**Tactical UI/UX Design System, Color Token Palette & Canvas Specs**

---

## 1. Tactical Color Tokens (Dark Mode First)
- **Background Main**: `#090D16` (Deep Tactical Navy)
- **Card Panel Surfaces**: `#121826` (Sleek Slate Container)
- **Border Dividers**: `#1F293D` (Subtle Grid Border)
- **Primary Accent**: `#00E5FF` (Cyan Beacon Glow)
- **Heatmap Low Density**: `rgba(0, 229, 255, 0.4)` (Cyan)
- **Heatmap Medium Density**: `rgba(255, 200, 0, 0.6)` (Amber Warning)
- **Heatmap High Density**: `rgba(255, 40, 80, 0.85)` (Red Rescue Priority)

## 2. Typography & Fonts
- **Primary Font**: `Inter`, `system-ui`, sans-serif.
- **Monospace Telemetry Font**: `JetBrains Mono`, `Fira Code`, monospace.

## 3. UI Component Specs
- **Confidence Metrics Card**: High-contrast probability percentage (`92% Probability`, `88% Confidence`) with visual progress ring.
- **Explainable AI (XAI) Drawer**: Side sliding panel displaying feature attribution bars (BLE, Wi-Fi RSSI, Audio, IMU).
- **Timeline Control Bar**: Video-player style scrubber with play/pause, step forward/back, and speed multiplier (`1x`, `2x`, `5x`).
